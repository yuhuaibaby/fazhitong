## 一、升级概述

在 v1.0 基础上，v2.0 小程序端保持原有 7 个核心功能模块不变，新增以下功能：

### 1.1 功能对照

| 模块 | v1.0 | v2.0 | 说明 |
|:-----|:-----|:-----|:-----|
| 首页 | ✅ | ✅ | 保留，优化交互 |
| 合同审查 | ✅ | ✅ | 保留，对接真实AI |
| 文书生成 | ✅ | ✅ | 保留，增加模板 |
| 法律咨询 | ✅ | ⭐升级 | 增加人工客服、律师 |
| 用工合规 | ✅ | ✅ | 保留 |
| 债务催收 | ✅ | ✅ | 保留 |
| 企业档案 | ✅ | ✅ | 保留，云端同步 |
| 人工客服 | ❌ | 🆕新增 | 工作时间在线客服 |
| 律师咨询 | ❌ | 🆕新增 | 图文/电话/视频 |
| 律所对接 | ❌ | 🆕新增 | 律所列表、律师预约 |
| 订单中心 | ❌ | 🆕新增 | 咨询订单、支付记录 |
| 消息中心 | ❌ | 🆕新增 | 通知消息 |

## 二、v1.0 功能保留

### 2.1 首页（SMEHome）

**保留功能**：
- 顶部搜索栏
- 问候语卡片（待办提醒）
- 四大核心功能入口（审查合同、生成文书、法律咨询、用工合规）
- 快捷工具（催款函、劳动合同、租赁合同、欠条）
- 我的待办
- AI推荐
- 本月使用统计

**v2.0 优化**：
- 数据从后端获取（不再使用 Mock）
- 支持下拉刷新
- 待办点击可跳转

### 2.2 合同审查（SMEContractReview）

**保留功能**：
- 上传区域（拍照/文件）
- 处理进度动画（5个步骤）
- 审查报告（风险评分、风险详情、修改建议）
- 已检查通过项目

**v2.0 优化**：
- 对接真实 AI 模型
- 支持 PDF/Word/图片
- 审查结果云端保存

### 2.3 文书生成（SMEDocumentGen）

**保留功能**：
- 模板选择（催款函、劳动合同、租赁合同）
- 表单填写（动态字段）
- 文书预览
- 下载/分享

**v2.0 优化**：
- 增加更多模板（欠条、合作协议等）
- 历史文书云端同步
- 支持自定义模板

### 2.4 法律咨询（SMEChat）

**保留功能**：
- AI对话界面
- 快捷问题
- 消息气泡样式
- 打字中动画

**v2.0 升级**：
- 增加人工客服入口
- 增加律师咨询入口
- 智能分流逻辑

### 2.5 用工合规（SMECompliance）

**保留功能**：
- 评分卡片
- 检测项目列表（可展开）
- 一键整改清单

### 2.6 债务催收（SMEDebtCollection）

**保留功能**：
- 四阶段选择（友好提醒、正式催收、最后通牒、法律诉讼）
- 阶段详情（建议行动、可用工具）
- 催收小贴士

### 2.7 企业档案（SMEArchive）

**保留功能**：
- Tab切换（合同、证照、待办）
- 合同列表（含到期提醒）
- 证照管理
- 待办列表

**v2.0 优化**：
- 数据云端同步
- 多端访问

## 五、技术实现

### 5.1 技术选型

| 组件 | 技术 | 说明 |
|:-----|:-----|:-----|
| 框架 | Taro 3 | 跨端框架 |
| UI | Taro UI / NutUI | 移动端组件库 |
| 状态管理 | Zustand | 轻量级状态管理 |
| 请求 | Taro.request + 封装 | HTTP 请求 |
| 实时通讯 | Socket.io-client | 客服聊天 |
| 支付 | Taro.requestPayment | 微信支付 |

### 5.2 与后端对接

**接口规范**：
- 基础 URL：`https://api.fazhitong.com/v1`
- 认证方式：JWT Token
- 请求格式：JSON

**核心接口**：

| 模块 | 接口 | 方法 | 说明 |
|:-----|:-----|:-----|:-----|
| 用户 | /user/login | POST | 微信登录 |
| 咨询 | /consultation/create | POST | 创建会话 |
| 咨询 | /consultation/messages | GET | 消息记录 |
| 律所 | /lawfirm/list | GET | 律所列表 |
| 律所 | /lawyer/list | GET | 律师列表 |
| 预约 | /booking/create | POST | 创建预约 |
| 订单 | /order/list | GET | 订单列表 |
| 支付 | /pay/create | POST | 创建支付 |
| 合同 | /contract/review | POST | 合同审查 |
