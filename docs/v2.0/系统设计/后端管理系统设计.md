# 后端管理系统设计文档

> 版本：v2.0 | 模块：PC 管理后台

---

## 一、系统概述

管理后台是法智通平台的运营管理中心，提供用户管理、内容管理、订单管理、数据统计等功能，支撑平台的日常运营和决策分析。

### 1.1 设计原则

- **易用性**：操作简单，学习成本低
- **实时性**：数据实时更新，支持实时监控
- **安全性**：权限控制，操作审计
- **可扩展**：模块化设计，支持功能扩展

### 1.2 技术选型

| 组件 | 技术 | 说明 |
|:-----|:-----|:-----|
| 框架 | React 18 | 现代前端框架 |
| UI 库 | Ant Design 5 | 企业级 UI 组件 |
| 状态管理 | Zustand | 轻量状态管理 |
| 请求 | Axios + React Query | 数据请求与缓存 |
| 图表 | ECharts | 数据可视化 |

## 二、功能模块

### 2.1 工作台（Dashboard）

**功能说明**：运营人员登录后的首页，展示关键指标和待办事项。

**页面元素**：

├─────────────────────────────────────────────────────────────────┤
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐              │
│  │ 今日UV  │ │ 新增用户 │ │ 咨询会话 │ │ 今日收入 │              │
│  │  1,234  │ │    +56  │ │    89   │ │ ¥3,450 │              │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘              │
│                                                                 │
│  ┌──────────────────────┐ ┌──────────────────────┐             │
│  │      收入趋势         │ │      用户增长         │             │
│  │   [折线图 7天]       │ │   [柱状图 7天]       │             │
│  └──────────────────────┘ └──────────────────────┘             │
│                                                                 │
│  ┌──────────────────────┐ ┌──────────────────────┐             │
│  │      待办事项         │ │      系统公告         │             │

**核心指标**：
- 今日 UV / PV
- 新增用户数

### 2.2 用户管理

**功能说明**：管理平台用户，查看用户详情，进行用户运营。

**页面结构**：

| 功能 | 说明 |
|:-----|:-----|
| 用户列表 | 分页展示，支持搜索、筛选、导出 |
| 用户详情 | 基本信息、会员信息、消费记录、咨询记录 |
| 用户画像 | 标签、活跃度、价值分层 |
| 黑名单 | 添加/移除黑名单用户 |

**列表字段**：
- 用户ID、头像、昵称、手机号
- 企业名称、会员等级
- 注册时间、最后登录
- 操作（查看详情、编辑、禁用）

---

### 2.3 律所管理

**功能说明**：管理入驻律所和律师，审核资质，配置服务。

**2.3.1 律所列表**

| 字段 | 说明 |
|:-----|:-----|
| 律所名称 | 律所全称 |
| 执业许可证号 | 营业执照编号 |
| 律师数量 | 入驻律师数 |
| 服务评分 | 用户平均评分 |
| 状态 | 待审核/正常/禁用 |
| 操作 | 审核/编辑/禁用 |

**2.3.2 律师列表**

| 字段 | 说明 |
|:-----|:-----|
| 律师姓名 | 真实姓名 |
| 所属律所 | 律所名称 |
| 执业证号 | 律师执业证编号 |
| 专业领域 | 民事/刑事/商事等 |
| 咨询次数 | 累计咨询次数 |
| 评分 | 用户评分 |
| 状态 | 待审核/在线/离线/禁用 |

**2.3.3 审核流程**

```
律师提交入驻申请
       ↓
管理员审核资质（执业证、身份证明）
       ↓
  ┌────┴────┐
  ↓         ↓
通过       驳回（说明原因）
  ↓
配置服务项目、定价
  ↓
上架展示
```

### 2.5 内容管理

**功能说明**：管理平台内容，包括知识库、模板、公告等。

**子模块**：

| 模块 | 说明 |
|:-----|:-----|

### 2.6 订单与财务

**功能说明**：管理咨询订单、委托订单，处理退款，查看财务数据。

**订单列表**：

| 字段 | 说明 |
|:-----|:-----|
| 订单号 | 唯一订单编号 |
| 用户 | 下单用户 |
| 商品类型 | 咨询/委托/会员 |
| 商品名称 | 具体服务名称 |
| 金额 | 订单金额 |
| 状态 | 待支付/已支付/已退款/已完成 |
| 支付时间 | 实际支付时间 |
| 操作 | 查看详情/退款 |

**财务统计**：
- 日/周/月收入趋势
- 各业务收入占比
- 退款统计
- 律所结算

### 2.7 数据统计

**功能说明**：多维度数据分析，支撑运营决策。

**统计维度**：

| 维度 | 指标 |
|:-----|:-----|
| 用户分析 | 新增用户、活跃用户、留存率、用户画像 |
| 业务分析 | 咨询量、转化率、满意度、响应时长 |
| 收入分析 | 营收趋势、客单价、复购率 |
| 内容分析 | 热门问题、高频合同类型、知识库使用率 |

**可视化**：
- 趋势折线图
- 占比饼图
- 排行榜
- 漏斗图

## 四、权限设计

### 4.1 角色定义

| 角色 | 说明 | 权限范围 |
|:-----|:-----|:---------|
| 超级管理员 | 系统最高权限 | 全部功能 |
| 运营管理员 | 日常运营管理 | 用户、内容、订单、数据 |
| 客服主管 | 客服团队管理 | 咨询管理、质检 |
| 客服专员 | 接待用户咨询 | 咨询会话处理 |
| 财务人员 | 财务相关操作 | 订单、财务统计 |
| 内容编辑 | 内容发布管理 | 知识库、模板、公告 |

### 4.2 权限控制

- 菜单权限：控制可访问的页面
- 按钮权限：控制可执行的操作
- 数据权限：控制可查看的数据范围
