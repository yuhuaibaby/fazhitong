# 法智通·企业版 v2.0 升级方案

> 版本：v2.0 | 日期：2026-09-03 | 状态：规划中

---

## 一、版本定位

### 1.1 版本关系

**v1.0 是基础，v2.0 是升级**

```
v1.0（基础版）                    v2.0（升级版）
┌─────────────────┐              ┌─────────────────┐
│  小程序前端原型  │      +       │  后端管理系统    │
│  7个核心页面     │      +       │  律所对接模块    │
│  Mock数据演示    │      +       │  人工客服系统    │
│  AI法律咨询     │      +       │  真实数据对接    │
└─────────────────┘              └─────────────────┘
```

### 1.2 升级内容

| 维度 | v1.0 | v2.0 |
|:-----|:-----|:-----|
| 产品形态 | 前端原型 | 完整产品（小程序 + 管理后台） |
| 数据来源 | Mock 数据 | 真实后端 API |
| 服务能力 | 仅 AI 咨询 | AI + 人工客服 + 律师 |
| 运营能力 | 无 | 完整后台管理系统 |
| 商业模式 | 演示 | 可运营 |

## 二、功能模块（完整）

### 2.1 小程序端功能

#### 基础功能（v1.0 已有）

| 模块 | 路由 | 功能说明 |
|:-----|:-----|:---------|
| **首页** | `/sme` | 问候语、待办提醒、四大功能卡片、快捷工具、AI推荐、本月统计 |
| **合同审查** | `/sme/contract-review` | 拍照/上传合同 → AI分析 → 风险报告（高/中/低风险、修改建议、法律依据） |
| **文书生成** | `/sme/document` | 催款函、劳动合同、租赁合同等模板，填空生成文书 |
| **法律咨询** | `/sme/chat` | AI对话式咨询，快捷问题，模拟AI回复 |
| **用工合规** | `/sme/compliance` | 入职流程检测，风险评分，整改建议 |
| **债务催收** | `/sme/debt-collection` | 四阶段催收流程（友好提醒→正式催收→最后通牒→法律诉讼） |
| **企业档案** | `/sme/archive` | 合同管理、证照管理、待办提醒 |

#### 新增功能（v2.0 升级）

| 模块 | 路由 | 功能说明 |
|:-----|:-----|:---------|
| **人工客服** | `/sme/chat/human` | 工作时间在线客服，复杂问题转接律师 |
| **律师咨询** | `/sme/chat/lawyer` | 图文/电话/视频咨询，付费服务 |
| **律所列表** | `/sme/law-firms` | 按地区、专业筛选律所 |
| **律师详情** | `/sme/lawyer/:id` | 律师简介、专业领域、评价、预约 |
| **预约咨询** | `/sme/booking` | 选择咨询方式、时间段，微信支付 |
| **订单中心** | `/sme/orders` | 咨询订单、委托订单、支付记录 |
| **消息中心** | `/sme/messages` | 系统通知、咨询消息、预约提醒 |

#### 法律咨询升级

```
v1.0: AI 咨询（单一）         v2.0: 三级咨询体系
┌─────────────┐              ┌─────────────────────────────────┐
│  AI 对话    │       →      │  🤖 AI咨询（免费，24h）          │
│  预设回复   │              │  👨‍⚖️ 人工客服（限时免费）        │
└─────────────┘              │  ⭐ 律师咨询（付费）             │
                             └─────────────────────────────────┘
```

**智能分流逻辑**：
1. 简单问题 → AI 直接回答
2. 复杂问题 → 转人工客服
3. 专业需求 → 推荐律师

## 七、总结

v2.0 在 v1.0 基础上进行以下升级：

1. **保留 v1.0 全部功能** - 首页、合同审查、文书生成、AI咨询、用工合规、债务催收、企业档案
2. **增加后端管理系统** - 用户管理、律所管理、订单管理、数据统计
3. **增加律所对接** - 律所入驻、律师展示、预约咨询、委托办案
4. **增加人工客服** - AI + 人工 + 律师三级服务体系
5. **支持真实运营** - 微信支付、数据持久化、用户认证
