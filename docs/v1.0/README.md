## 文档说明

### 1. 需求文档

| 文档 | 用途 | 建议阅读对象 |
|:-----|:-----|:-------------|
| **PRD v1.0** | 产品定位、用户画像、系统架构、各功能模块详细需求、非功能需求 | 前后端工程师、测试工程师 |
| **建设方案**（docx/md） | 市场分析与需求洞察、产品定位与核心功能设计、商业模式与定价策略、推广策略 | 产品经理、运营人员 |

### 2. 交互原型

交互原型源码位于 `../../`（项目根目录），技术栈：

- React 19 + TypeScript + Vite 7 + Tailwind CSS 3
- 路由：React Router 7
- 图标：Lucide React

运行方式：

```bash
# 在项目根目录执行
npm install
npm run dev    # 访问 http://localhost:3000
```

### 3. 原型说明

包含页面-路由对照表、目录结构说明、Mock 数据说明、已知限制等。

## 核心功能模块

| 模块 | 路由 | 说明 |
|:-----|:-----|:-----|
| 首页 | `/sme` | 待办提醒、四大功能卡片、快捷工具 |
| 合同审查 | `/sme/contract-review` | 拍照/上传合同，AI分析风险 |
| 文书生成 | `/sme/document` | 催款函、劳动合同等模板填空 |
| 法律咨询 | `/sme/chat` | AI对话式法律咨询 |
| 用工合规 | `/sme/compliance` | 企业用工风险检测 |
| 债务催收 | `/sme/debt-collection` | 应收账款逾期应对流程 |
| 企业档案 | `/sme/archive` | 企业信息与文档归档 |
