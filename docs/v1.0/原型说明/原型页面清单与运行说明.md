# 交互原型：页面清单与运行说明

原型源码位于 `02-交互原型/`，为独立 React 工程，仅包含企业版小程序部分。

## 一、运行方式

```bash
cd 02-交互原型
npm install
npm run dev      # 开发模式，http://localhost:3000
npm run build    # 生产构建（已验证通过），产物在 dist/
```

环境要求：Node.js 18 及以上。首次进入自动重定向到小程序首页 `/sme`。

## 二、页面 / 路由对照表

| 路由 | 页面文件 | 功能 | 入口 |
|:-----|:---------|:-----|:-----|
| `/sme` | `src/sme/pages/SMEHome.tsx` | 首页：待办提醒、四大功能卡片、快捷工具、我的待办 | 底部 Tab「首页」 |
| `/sme/contract-review` | `src/sme/pages/SMEContractReview.tsx` | 合同智能审查：拍照/上传 → 审查结果（风险点、修改建议） | 首页「审查合同」卡片、底部 Tab「审查」 |
| `/sme/document` | `src/sme/pages/SMEDocumentGen.tsx` | 法律文书生成：催款函/劳动合同/租赁合同/欠条等模板填空出文书 | 首页「生成文书」卡片、快捷工具 |
| `/sme/chat` | `src/sme/pages/SMEChat.tsx` | 法律咨询：AI 对话式咨询（聊天界面，含历史记录） | 首页「法律咨询」卡片、底部 Tab「咨询」 |
| `/sme/compliance` | `src/sme/pages/SMECompliance.tsx` | 用工合规检测：用工风险自查与结果解读 | 首页「用工合规」卡片 |
| `/sme/debt-collection` | `src/sme/pages/SMEDebtCollection.tsx` | 债务催收：应收账款逾期应对流程（含催款函联动） | 首页待办/快捷工具「催款函」 |
| `/sme/archive` | `src/sme/pages/SMEArchive.tsx` | 企业档案（我的）：企业信息、文档归档 | 底部 Tab「我的」 |

底部 Tab 导航定义在 `src/sme/components/SMELayout.tsx`：**首页 / 审查 / 咨询 / 我的**（4 个常驻入口）。

## 三、目录结构

```
src/
├── main.tsx                  # 入口，挂载 BrowserRouter
├── App.tsx                   # 路由表（仅企业版 7 个路由）
├── index.css                 # 全局样式与主题变量（主色 #1E3A5F 深蓝 / #C4973B 金）
├── App.css                   # 辅助样式
└── sme/
    ├── components/
    │   └── SMELayout.tsx     # 小程序外壳：居中手机宽度容器 + 底部 Tab
    ├── data/
    │   └── mockData.ts       # 全部演示数据（首页待办、审查结果、聊天记录、模板、合规项、催收流程、档案）
    └── pages/                # 7 个页面组件（见上表）
```

## 四、Mock 数据说明

所有页面数据集中在 `src/sme/data/mockData.ts`，按导出对象划分：

| 导出对象 | 消费页面 | 内容 |
|:---------|:---------|:-----|
| `homeData` | SMEHome | 问候语、待办汇总、功能卡片、快捷工具、待办列表 |
| `contractReviewResult` | SMEContractReview | 示例审查报告（风险等级、条款风险点、修改建议） |
| `documentTemplates` | SMEDocumentGen | 文书模板清单（催款函、劳动合同、租赁合同、欠条） |
| `chatHistory` | SMEChat | 预置咨询对话记录 |
| `complianceCheck` | SMECompliance | 用工合规检查项与结果 |
| `debtCollectionFlow` | SMEDebtCollection | 催收流程步骤 |
| `companyArchive` | SMEArchive | 企业档案信息与归档文档 |

对接真实后端时，仅需替换各页面取数逻辑，保持字段结构可参考 `01-需求文档/法智通企业版_PRD_v1.0.md` 中各模块的接口与数据说明。

## 五、已知限制

1. 路由为 BrowserRouter 且构建 base 为相对路径：**直接刷新/直链内页路由会白屏**，请从首页进入后点击导航（与主工程行为一致）。
2. 上传、拍照、发送消息等交互为前端演示，不产生真实网络请求。
3. 原型按 375px 左右移动端宽度设计（`max-w-md` 居中），桌面浏览器打开时左右留白属正常表现。
