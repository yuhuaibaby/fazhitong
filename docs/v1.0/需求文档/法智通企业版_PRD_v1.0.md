## 1. 产品概述

### 1.1 产品定位

法智通·企业版是专为宁夏地区小微企业打造的AI法律服务SaaS产品。产品以微信小程序为主要载体，以"看得懂、用得起、真管用"为核心理念，帮助没有专职法务的小微企业主自助处理高频法律事务。

**核心设计原则（按优先级排序）：**

1. **极简操作**：任何功能3步内完成，无需学习成本
2. **大白话交互**：说人话、给结论、指方向
3. **移动优先**：微信小程序为主，H5/PC为辅
4. **即时反馈**：AI处理过程可视化，结果秒出
5. **场景化设计**：围绕真实经营场景，而非法律专业分类

### 1.2 目标用户

| 用户角色 | 占比 | 核心场景 | 技术能力 |
|:---------|:-----|:---------|:---------|
| 小微企业主 | 60% | 合同审查、债务催收、法律咨询 | 微信/抖音熟练，不愿学新软件 |
| 行政/财务人员 | 25% | 文书生成、用工合规、档案管理 | Word/Excel熟练，手机办公常态 |
| HR专员 | 10% | 用工合规、劳动合同、员工手册 | 办公软件熟练，了解基础HR法规 |
| 个体工商户 | 5% | 租赁合同、借贷协议、法律咨询 | 基础手机操作能力 |

### 2.3 文书生成

#### 2.3.1 功能目标
让非法律专业的小微企业主，通过填空式交互，在5分钟内生成一份可用的法律文书。

#### 2.3.2 设计原则
- **填空式**：像填表一样生成文书，不需要写任何法律术语
- **模板化**：预设常见场景，用户只需改数字和名字
- **预览即所得**：边填边看，实时预览生成的文书

#### 2.3.3 支持文书类型（V1.0）

| 分类 | 文书类型 | 使用场景 | 输入字段数 |

| 劳动用工 | 劳动合同 | 员工入职 | 8项 |
| 劳动用工 | 员工手册 | 公司制度公示 | 6项 |
| 劳动用工 | 离职协议 | 协商解除 | 7项 |
| 劳动用工 | 催告函（旷工） | 员工管理 | 5项 |
| 债权债务 | 催款函 | 客户拖欠货款 | 6项 |
| 债权债务 | 借条/欠条 | 民间借贷 | 5项 |
| 债权债务 | 还款协议 | 债务重组 | 7项 |
| 租赁 | 房屋租赁合同 | 租房/租商铺 | 10项 |
| 租赁 | 场地使用协议 | 临时场地 | 6项 |
| 经营 | 合作协议 | 项目合作 | 8项 |
| 经营 | 保密协议 | 商业合作 | 5项 |
